# Recipe: translations (i18n)

## Problem

Literal text in a component cannot be translated, and two catalogs drift apart without anyone noticing.
JSON hides duplicate keys: `JSON.parse` keeps the last one silently.

## Rule

- Catalogs live at the top level, outside `src/`: `messages/<locale>/<namespace>.json`.
  The files mirror the route tree: `common.json`, `nav.json`, `metadata.json`, then one per page folder.
- `en` is the shape source. Every locale has the same files, keys, value kinds and `{placeholders}`.
- Locales, the default and the cookie name are declared ONCE, in `src/lib/i18n/config.ts`.
- No literal user-facing text in a component. A Server Component loads the dictionary and passes the slice a
  Client Component needs as a `copy` prop.
- French uses the straight apostrophe (`'`), never the curly one (`’`).
- Edit both catalogs together, with small targeted edits. Never rewrite a whole catalog file.
- Checks: `pnpm check:i18n` (folders, files, keys, value kinds, placeholders, curly apostrophes) and
  `pnpm check:json` (invalid JSON and duplicate keys, recursive).

## Code

```ts
// src/lib/i18n/config.ts (no "server-only": Client Components need it too)
export const locales = ["en", "fr"] as const;
export type Locale = (typeof locales)[number];
export const defaultLocale: Locale = "en";
export const LOCALE_COOKIE = "NEXT_LOCALE";

export function isLocale(value: unknown): value is Locale {
  return typeof value === "string" && (locales as readonly string[]).includes(value);
}

/** `[locale]` is a dynamic segment: `/de/...` still renders, in the default locale. */
export function resolveLocale(value: unknown): Locale {
  return isLocale(value) ? value : defaultLocale;
}
```

```ts
// src/lib/i18n/get-dictionary.ts
import "server-only";
import { cache } from "react";
import type { Locale } from "./config";
import type enCommon from "@messages/en/common.json";
import type enInvoices from "@messages/en/invoices.json";

export type Dictionary = { common: typeof enCommon; invoices: typeof enInvoices };
type Loaders = { [N in keyof Dictionary]: () => Promise<{ default: Dictionary[N] }> };

// One literal import per file. A bundler cannot follow a templated path, and a French file
// whose shape drifts from the English one fails the typecheck right here.
const loaders: Record<Locale, Loaders> = {
  en: { common: () => import("@messages/en/common.json"), invoices: () => import("@messages/en/invoices.json") },
  fr: { common: () => import("@messages/fr/common.json"), invoices: () => import("@messages/fr/invoices.json") },
};

/** Memoized per request: the layout and the page share one load. */
export const getDictionary = cache(async (locale: Locale): Promise<Dictionary> => {
  const load = loaders[locale];
  const [common, invoices] = await Promise.all([load.common(), load.invoices()]);
  return { common: common.default, invoices: invoices.default };
});
```

```ts
// src/lib/i18n/format.ts
/** Fills `{name}` placeholders. check:i18n keeps them identical in every locale. */
export function format(template: string, values: Record<string, string | number>): string {
  return template.replace(/\{(\w+)\}/g, (match, key: string) => (key in values ? String(values[key]) : match));
}
```

```ts
// src/lib/i18n/pick-locale.ts (called by src/proxy.ts for a path without a locale)
import type { NextRequest } from "next/server";
import { defaultLocale, isLocale, LOCALE_COOKIE, type Locale } from "./config";

export function pickLocale(request: NextRequest): Locale {
  const fromCookie = request.cookies.get(LOCALE_COOKIE)?.value;
  if (isLocale(fromCookie)) {
    return fromCookie;
  }
  const wanted = (request.headers.get("accept-language") ?? "")
    .split(",")
    .map((part) => {
      const [tag, q] = part.trim().split(";q=");
      return { base: tag.split("-")[0].toLowerCase(), q: q ? Number(q) : 1 };
    })
    .sort((a, b) => b.q - a.q);
  for (const { base } of wanted) {
    if (isLocale(base)) {
      return base;
    }
  }
  return defaultLocale;
}
```

```tsx
// src/app/[locale]/(app)/invoices/page.tsx
import { InvoiceList } from "@/components/invoices/invoice-list";
import { resolveLocale } from "@/lib/i18n/config";
import { getDictionary } from "@/lib/i18n/get-dictionary";

export default async function InvoicesPage({ params }: { params: Promise<{ locale: string }> }) {
  const locale = resolveLocale((await params).locale);
  const dict = await getDictionary(locale);
  // A Client Component receives its slice as props: no dictionary in the bundle.
  return <InvoiceList copy={dict.invoices.list} />;
}
```

Also: `tsconfig.json` maps `"@messages/*": ["./messages/*"]` with `resolveJsonModule: true`, and the
`[locale]` layout exports `generateStaticParams()` returning one entry per locale and sets `<html lang={locale}>`.

## Traps

- A templated ``import(`@messages/${locale}/x.json`)`` cannot be analysed. A typo becomes a runtime failure in
  one locale only. Write one literal import per file.
- `error.tsx` is a Client Component, so `getDictionary` (server-only) cannot run there. Import the small
  `common.json` of each locale directly.
- `not-found.tsx` and `forbidden.tsx` receive no `params`. Read the locale from the locale cookie.
- The edge proxy matcher must exclude `api`: a locale prefix on `/api/*` turns every browser call into a redirect.
- A curly apostrophe in French breaks string matching in tests and search. The check flags it.
- Duplicate keys parse fine: the first value is silently lost. That is why `check:json` exists.
- A whole-file rewrite of a catalog loses keys that other screens read. Edit the few keys you need.
